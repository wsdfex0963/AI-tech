## 0. 一句話流程


## 1. 抽欄位：只取「算錢要用的」，個資一律不落地

| 要抽 | 不准寫進 Notion／repo |
|---|---|
| 公司、可認股數、每股認購價、應繳股款、認購狀態 | 身分證字號、出生年月日 |
| 認購期間、列印繳款書期間、繳款期間（含截止時間，如 15:30） | 行動電話、戶籍／通訊地址 |
| 繳款帳號、集保帳號 → **只留前 4 碼＋末 4 碼**，中間遮罩 | 員工編號（非必要不寫） |

- 驗算：`可認股數 × 每股認購價 = 應繳股款`，不符就停下來問。
- 民國年 → 西元：`+1911`（115 年 = 2026）。
- 通知信常見陷阱：「**請勿提前繳款**」「逾期視同放棄」「列印繳款書截止有時間點」——全部寫進待辦說明欄。

## 3. 趨勢分析方法（可重複、參數可換）

**核心邏輯**：結算日股價 ≈ 市場給的 P/E × 該時點「往後 12 個月」EPS；總報酬 = 價差 + 結算前已除息的現金股利。

1. **查證（每次都要重查，不沿用舊數字）**：最新月自結累計 EPS 與年增率、子公司拆分（銀行／證券）、前一年全年 EPS、法人對今明兩年 EPS 預估、配發率政策、最近一次除息日、現價（標日期）、每股淨值。
2. **稀釋調整**：法人預估多半是增資前股本 → `EPS × 舊股本 / (舊股本 + 新股)`。
3. **三情境**：Bear／Base／Bull 各給 EPS 路徑與 P/E；P/E 參考該股歷史區間與同業，並用 P/B 交叉檢查合不合理。
4. **結算點規則**：
   - 年底結算 → 前瞻 EPS 用下一年
   - 年中結算 → 兩年各半；**且必須先確認當年除息日**，在除息前賣就拿不到那筆股利
5. 跑 `scripts/scenario.py`（參數全在 DEFAULT 或外部 JSON），輸出結算表＋損益兩平股價。
6. 結論要講「報酬主要靠什麼」（EPS 成長 vs 股利 vs 估值），並列出 3–4 個每次結算前要看的指標＋簡單決策規則。

```bash

python3 .claude/skills/employee-stock-subscription/scripts/scenario.py my.json    # 換股票/換假設
```
